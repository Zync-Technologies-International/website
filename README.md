# RFID HaaS · Pre-Seed Pitch Deck (KSUM)

Vite + React + TypeScript + Tailwind v3 + lucide-react.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build to dist/
npm run preview
```

## Controls
- `→` / `Space` next · `←` previous · `F` fullscreen · `O` overview · `Esc` close overview
- Slide 5: Capex vs HaaS toggle · Slide 8: Q1–Q4 roadmap tabs

## Editing content
All slide content lives in `src/slides.tsx`; shell and navigation in `src/App.tsx`.
